# Cargo-Statistics

**Author:** GruntzCZ  
**Version:** 1.0

## Description

Cargo Statistics is a simple Game Script for OpenTTD that keeps track
of the total amount of cargo transported by the player's company.

Statistics for each available cargo type are displayed in the Story Book.

The script automatically detects the cargo types available in the game.
Cargo names are displayed using the language selected in OpenTTD.

The script has been tested with all standard cargo types and climates
included in vanilla OpenTTD.

NewGRF cargo types should be detected automatically.

## Compatibility

This Game Script is intended to track the player's company.
Statistics of competing companies are not displayed.
